# TaskFlow - Task Management Application

A modern, professional task management application built with React.

## Features

-  Create, edit, delete tasks
-  Multiple project/lists support
-  Dark/Light mode toggle
-  Task filtering and sorting
-  Priority levels (Low, Medium, High, Urgent)
-  Task status (Todo, In Progress, Done)
-  Local storage persistence
-  Responsive design

## Tech Stack

- React 18
- Vite
- Lucide React Icons
- Framer Motion

## Installation

```bash
npm install
npm run dev
